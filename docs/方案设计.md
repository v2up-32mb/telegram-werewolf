# Telegram 狼人杀 Bot —— 方案设计

> 版本：v0.3（核心规则终审版）
> 状态：核心玩法与产品规则终审完成，未进入开发
> 说明：本文档为「玩法与产品」总览；**详细规则以 [游戏流程设计.md](游戏流程设计.md) 为唯一权威来源**，本文档不重复罗列细节。

---

## 1. 项目概述

基于 Telegram Bot 打造一个纯私聊模式的狼人杀游戏：

- 玩家无需建群、无需拉 Bot 进群、无需给 Bot 任何授权
- Bot 担任「主持人 + 广播中心」
- 房主创建「逻辑房间」，生成邀请链接，朋友点链接即可入房
- 身份、夜间行动、投票全部通过私聊完成，白天发言由 Bot 实时转播

---

## 2. 核心定位：纯私聊模式（方案 B）

> Bot = 主持人 + 广播中心。玩家只跟 Bot 私聊，不需要群组。

相较群组模式的差异与优势：

- **零门槛**：不建群、不拉 Bot、不授权
- **隐私**：玩家之间互不知道对方 Telegram 账号
- **跨圈子**：任意好友都能通过链接加入，不受群关系限制

---

## 3. 游戏阶段状态机

```
等待大厅 → 发牌确认 → 夜间 → 白天发言 → 白天投票 →（循环）→ 结算 → 等待大厅
```

详细阶段流转见 [游戏流程设计.md](游戏流程设计.md)。

## 4. 角色配置与技能

MVP 先做 **6 人局**跑通完整闭环；后续 8/9 人局加入猎人，12 人局加入守卫。

| 人数 | 配置 |
|---|---|
| 6 人（MVP 首发） | 2 狼 + 1 预言家 + 1 女巫 + 2 平民 |
| 8 人 | 3 狼 + 1 预言家 + 1 女巫 + 1 猎人 + 2 平民 |
| 9 人 | 3 狼 + 预言家 + 女巫 + 猎人 + 3 平民 |
| 12 人（后期） | 4 狼 + 预言家 + 女巫 + 猎人 + 守卫 + 4 平民 |

角色技能：

- **狼人**：夜间刀 1 人；狼人互相认识（狼人讨论频道互通）
- **预言家**：每夜验 1 人，得知「狼人 / 好人」（二分，不细分神职）
- **女巫**：1 瓶解药 + 1 瓶毒药；首夜能否自救由房主创建时选择
- **猎人**：被刀 / 票死 / 枪杀可开枪带走 1 人（被毒死不能开枪）
- **守卫**（后期）：每晚守护 1 人，经典规则
- **平民**：无技能，靠发言和投票

---

## 5. 核心玩法机制（摘要）

- **白天发言**：麦序模式，按次序依次发言，结束点「结束发言」按钮
- **夜间行动**：守卫 → 狼人 → 女巫 → 预言家（无守卫跳过）；狼人刀人「投票按钮 + 广播讨论」并行
- **投票**：私聊匿名收集，结束后统一公布结果（含「谁投了谁」）
- **胜负**：可配置「屠边」/「屠城」；6 人局默认屠城，8/9 人局默认屠边；严格按行动顺序即时判定

详细规则见 [游戏流程设计.md](游戏流程设计.md)。

## 6. 积分系统（摘要）

- 胜利 +5、失败 0、死亡躺赢 +2、恶意退出失败 -5
- 初始 0 分、可为负；用于排行榜排名 + 房主强制解散扣分（扣 10）

详见 [游戏流程设计.md](游戏流程设计.md)「结算与系统」。

## 7. 概念数据模型（需记录的信息）

以下仅为「需要记录什么信息」的概念描述，不涉及具体存储方式：

- **房间**：房间码、房主、状态、当前阶段、轮次、配置、创建时间
- **玩家**：所属房间、账号标识、游戏昵称、座位号、角色、存活状态、票数
- **转播记录**：房间、序号、座位号、内容、时间（保证发言有序）
- **夜间行动**：房间、轮次、行动者、行动类型、目标
- **战绩**：分角色胜负场次、积分、总场次（其余指标由这些数据计算得出）

---

## 8. 关键难点与风险

1. **广播风暴与限流**：多人同时发言，消息量激增，需排队 + 排序
2. **顺序一致性**：并发消息按时间戳排序，避免「后发先至」
3. **身份保密**：转播只显示座位号 + 游戏昵称，角色信息永不出现在广播中
4. **掉线 / 屏蔽**：玩家屏蔽 Bot 后收不到消息，需超时托管
5. **超时兜底**：夜间 / 发言限时，超时按默认选择处理，防止一人卡全场
6. **容灾**：Bot 重启后游戏状态不保留，未结束房间作为中止局结束并通知玩家；不结算胜负和积分、不计入胜负场次，但保留中止记录

## 9. MVP 分阶段里程碑

| 阶段 | 内容 | 角色 |
|---|---|---|
| P0 | 建房 + 邀请链接 + 入房 | 无 |
| P1 | 6 人局发牌 + 夜间（狼人刀人 / 预言家验人 / 女巫用药） | 狼、预言家、女巫 |
| P2 | 白天麦序发言 + 匿名投票 | 平民（完整 6 人局闭环） |
| P3 | 8 / 9 人局 + 掉线托管 + 猎人 | 猎人 |
| P4 | 12 人局 + 守卫 + 战绩 + 排行榜 + 多房间并发 | 守卫 |
