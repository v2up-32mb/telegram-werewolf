# 测试验收清单

本清单逐条映射 [游戏流程设计.md](游戏流程设计.md) 的 MVP 规则，用于自动化
与人工验收。MVP 范围为 6 人局：2 狼 + 预言家 + 女巫 + 2 平民（默认屠城）。

「覆盖位置」列只标注仓库中真实存在的测试/场景文件；未标注的条目为
**人工验收**（真实 Bot 冒烟，见 Task 46）。
